# Claude Code plugin

What Factwright loads into each Claude Code session, through Claude Code's own flags:
- **Skills:** fit check, tailored resume, application answers, interview prep and more.
- **MCP server:** the tools Claude uses instead of a shell, from saving a posting to rendering a resume.
- **Hooks:** tell the app when a run finishes or is waiting on you.

It's loaded for a session only. Your own Claude Code settings are never changed.

**Status:** not started. It comes in phases 2 and 3 of the [roadmap](../../docs/roadmap.md).
