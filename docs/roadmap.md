# Roadmap

Factwright is built in phases, and each one ends with something that works.

| Phase | What it delivers | Status |
|---|---|---|
| 0. Name | The name, the domain and this GitHub home | Done |
| 1. Setup | This repo: layout, tooling, CI and docs | In progress |
| 2. Prototype | Proof that the app can run your own Claude Code safely: a run starts, asks you questions, uses Factwright's tools and finishes, without touching your login | Next |
| 3. Desktop app | The dashboard becomes a real app. Run buttons start Claude on a job, and results land in the right place on their own | Planned |
| 4. Cloud | End-to-end encrypted sync across your computers and your phone, with a private store per account | Planned |
| 5. For everyone | Onboarding: import your resume, build your fact bank through an interview, and set your own job criteria | Planned |
| 6. Beta | Signed installers for Mac and Windows, automatic updates, a website, and the first outside users | Planned |
