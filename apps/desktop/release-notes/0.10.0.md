Factwright runs on a newer engine: Electron 44, with Chromium 152.

- **Newer inside:** Factwright's window runs on Chromium 152, with the security fixes and improvements since Chromium 150. Nothing changes in how you use it.
- **macOS 13 or later on a Mac:** Electron 44 needs macOS 13 Ventura or later. A Mac on macOS 12 keeps Factwright 0.9.3, which goes on working.
