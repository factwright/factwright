A security update: Factwright reads job pages more safely, and runs on Electron 44.9.3.

- **Job pages without Brotli:** Factwright no longer unpacks a page sent with Brotli compression. A flaw in Node.js's Brotli decoder, which comes with Electron, could let a page made for it run code on your computer.
- **Electron 44.9.3:** it blocks the eMudhra certificates whose keys turned out to be recoverable, so someone who can see your network traffic can't use them to pose as a site Factwright connects to. It also has Chromium's latest security fixes.
