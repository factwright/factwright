On a Mac, Factwright no longer reaches into your browsers' folders when it opens, which macOS blocked in 0.9.0.

- **No warning as it opens:** Factwright leaves your browsers alone until you set one up.
- **Save to Factwright, in a window of its own:** choose Browser extension in the sidebar to see where each browser stands, and set one up to save jobs straight to Factwright on this computer, with Save to Factwright 0.2 or later. On a Mac, macOS may ask you to allow it: choose Allow.
- **If macOS says no:** the window shows how to allow it in System Settings, with a button that opens the right place.
