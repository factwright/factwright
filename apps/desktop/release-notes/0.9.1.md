Factwright asks before it sets up your browsers, so a Mac shows no more “Data Access Blocked”.

- **Nothing reached at start:** on a Mac, Factwright no longer looks in your browsers' folders when it opens, which macOS blocked in 0.9.0.
- **Save to Factwright, in a window of its own:** choose Browser extension in the sidebar to see where each browser stands, and set one up to save jobs straight to Factwright on this computer. On a Mac, macOS asks you once for each browser: choose Allow.
- **If you chose Don't Allow:** the window shows how to allow it in System Settings, with a button that opens the right place.
