Factwright gets you past Claude Code's first screens, and its Claude Code commands work in any new terminal.

- **Claude Code's first screens:** a Claude Code that had never been opened stopped Factwright's setup check on the screens it shows the first time. Factwright now marks them done for you. If they show anyway, the Your Claude card says to press Enter through them in Claude's panel.
- **Commands that work in a new terminal:** on Windows, Claude Code's installer doesn't add it to your PATH, so `claude` wasn't found. Factwright's commands now start Claude Code by its whole path, and link to Anthropic's guide to adding it to your PATH.
- **Claude Code, not Claude Desktop:** on Windows, an older Claude Desktop can answer to `claude` and open itself instead. Factwright now passes over it and finds Claude Code.
- **Ready when Claude is:** Your Claude reads Ready once Claude Code is waiting for you to type, and no longer holds up the buttons that start other runs.
