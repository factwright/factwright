A fact bank that grows as you go, and cover letters.

- **Your fact bank grows as Claude writes:** while it tailors a resume, answers an application's questions or gets you ready for an interview, Claude asks about what the job wants that your facts don't show yet, when you likely have it. Your answers become facts.
- **Unverified, at the top of the Fact bank:** the facts from your answers, each with the job and the question it came from. Verify, edit or delete them. Claude uses an answer in the run you gave it, and asks before using an unverified fact again.
- **Cover letters:** a Cover letter button on each job writes one in your own voice, from your facts and what's on file for the job. It comes in the same template as the job's resume, with a Copy text button for application forms.
- **Things you've said you don't have** are kept, so Claude never asks twice, and you can undo one if it changes.
