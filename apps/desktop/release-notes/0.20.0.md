Questions for Claude are conversations now: reply to an answer, with a screenshot if you like, and Claude answers from everything said so far.

- **Reply to Claude's answers:** each answer in a job's Questions for Claude has a box under it to reply in. Ask a follow-up, push back, or say what's happened since, and Claude answers from the whole conversation, its own earlier answers included, as well as everything on file for the job. Enter sends, and Shift-Enter starts a new line.
- **Screenshots with a reply:** paste one into the reply box, drop it there, or pick it with Add screenshots, such as the recruiter's next email, and Claude reads it with your reply.
- **The keyboard stays where you're typing:** with Claude's work shown, a task that starts no longer takes the keyboard from a box you're typing in, so your next words don't go to Claude Code.
