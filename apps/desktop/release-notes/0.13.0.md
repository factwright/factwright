Profile gets ready for filling in job applications, which the browser extension's next version brings.

- **For applications, in Profile:** what application forms ask that a resume doesn't say, such as your pronouns, the countries you can work in without a visa, and how you heard of a job. Your street, postal code and equal-opportunity answers stay on this computer only: they never sync, and Claude never sees them.
- **Filling applications, with the extension's next version:** Fill this application opens a panel beside a job's application form. Factwright answers each field from Profile, the job's own resume and what you sent before, and uploads the job's resume, for you to check and submit yourself. It never submits.
- **The extension is called Factwright now:** the app's window for it is called Browser extension.
