A security update: Factwright runs on Electron 44.10.1, with Node.js 24.22.1.

- **Electron 44.10.1:** its Node.js fixes a flaw in the Brotli decoder (CVE-2026-111497), which a page or server made for it could use to run code on your computer. 0.12.1 already kept job pages from reaching it, and now sync's connection is covered too.
- **Updated libraries,** among them the ones that build Factwright's installers and its updates.
